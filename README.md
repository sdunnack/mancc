# mancc

Tools and prototypes for Manchester Country Club (MANCC), maintained as a collection of
independent projects in this monorepo.

## Projects

### [`ringers/`](ringers) — Golf League Ringers & Birdies
Data pipeline and static site for the club's golf league Ringers and Birdies standings.

- [`ringers/docs/`](ringers/docs) — static site (published via GitHub Pages). `scores.json` is
  generated by `scripts/fetch.py` and read client-side by `index.html`.
- [`ringers/scripts/`](ringers/scripts) — Python data fetcher (`fetch.py`) run on a schedule by
  GitHub Actions. It calls the Golf Genius API, extracts hole-by-hole scores for tracked players,
  and writes `docs/scores.json`. Falls back to mock data (`golf_genius/mock_data.py`) when no API
  key is configured, so the site can be developed without real credentials.
- [`ringers/documentation/`](ringers/documentation) — reference material, including the Golf
  Genius API spec (`golfgeniusapiv2.apib`).

```bash
python ringers/scripts/fetch.py
```

### [`lottery/`](lottery) — Tee time sign-up prototype
A local-only Node/Express prototype of a tee time sign-up system (see
[`plans/lottery-plan.md`](plans/lottery-plan.md) for the original edge-hosted design), using a
JSON file as its data store. Includes member/event registration, an admin dashboard, and a
"browse groups to join" flow. See [`lottery/README.md`](lottery/README.md) for details and setup.

```bash
cd lottery
npm install
npm start
```

### [`redesign/`](redesign) — Club website redesign mockup
Static HTML/CSS pages (club, dining, golf, membership, tournaments, women's division) prototyping
a redesign of the club's public website.

### [`plans/`](plans)
Design docs for in-progress or proposed features:
- [`lottery-plan.md`](plans/lottery-plan.md) — original edge-hosted (Cloudflare) design for the
  tee time sign-up system.
- [`ringer-and-birdie-plan.md`](plans/ringer-and-birdie-plan.md) — design notes for the Ringers
  and Birdies league scoring feature.
